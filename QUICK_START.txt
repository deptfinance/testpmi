🚀 INSTALASI PERTAMA KALI (hanya perlu 1x):
─────────────────────────────────────────────────────────────

1. Buka Terminal / Command Prompt
2. Masuk ke folder project:

   cd /path/to/testpmi

3. Install library Python:

   Linux/Mac: pip3 install -r requirements.txt
   Windows:   pip install -r requirements.txt

4. Install Chromium browser:

   Linux/Mac: python3 -m playwright install chromium
   Windows:   python -m playwright install chromium

5. Verifikasi:

   Linux/Mac: python3 -c "from playwright.async_api import async_playwright; print('✓ OK')"
   Windows:   python -c "from playwright.async_api import async_playwright; print('✓ OK')"

   Jika output "✓ OK" → Instalasi berhasil!


🎯 CARA PAKAI (setiap kali ingin cek):
─────────────────────────────────────────────────────────────

Linux/Mac:
   python3 cek_pmi.py AU610053

Windows:
   python cek_pmi.py AU610053

Ganti "AU610053" dengan nomor paspor Anda

❌ TROUBLESHOOTING CEPAT:
─────────────────────────────────────────────────────────────

Error "No module named 'playwright'":
   → Jalankan: pip3 install playwright

Error "Chromium not found":
   → Jalankan: python3 -m playwright install chromium

Error "command not found":
   → Ganti python3 dengan python (untuk Windows)

Error "nomor paspor tidak diberikan":
   → Tambahkan nomor paspor di command
   → Contoh: python3 cek_pmi.py AU610053

Untuk detail lengkap, buka file SETUP.md
