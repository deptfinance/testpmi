1️⃣  PUSH KE GITHUB

    $ git init
    $ git add .
    $ git commit -m "PMI bot untuk Render"
    $ git remote add origin https://github.com/USERNAME/cek-pmi-bot
    $ git push -u origin main

    ⚠️  Ganti USERNAME dengan GitHub username Anda!

2️⃣  BUKA RENDER.COM

    https://render.com
    Sign up (gratis)
    Authorize dengan GitHub

3️⃣  BUAT WEB SERVICE

    Dashboard → "New +" → "Web Service"
    Select repository: cek-pmi-bot
    Click "Connect"

4️⃣  SETUP & DEPLOY

    Name: cek-pmi-bot
    Runtime: Docker
    Dockerfile: Dockerfile.render

    Environment Variables:
    TELEGRAM_TOKEN = [token dari @BotFather]

    Click "Create Web Service"

5️⃣  TUNGGU & TEST

    Wait 3-5 menit untuk deployment

    Check logs di Render:
    "Bot siap menerima pesan dari Telegram"

    Test di Telegram:
    /start → Bot should respond
    /cek AU610053 → Bot should process

✅ SELESAI! BOT LIVE 24/7!
