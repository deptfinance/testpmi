📋 5-STEP DEPLOYMENT
═══════════════════════════════════════════════════════════════

1️⃣  PUSH KE GITHUB

    git init
    git add .
    git commit -m "Initial commit"
    git remote add origin https://github.com/USERNAME/cek-pmi-bot
    git push -u origin main

    (Ganti USERNAME dengan GitHub username Anda)

2️⃣  BUKA RENDER.COM

    https://render.com
    Sign up dengan GitHub
    Authorize dengan GitHub

3️⃣  CREATE WEB SERVICE

    Klik "New +" → "Web Service"
    Search & select repo: cek-pmi-bot
    Click "Connect"

4️⃣  CONFIGURE SERVICE

    Name: cek-pmi-bot
    Runtime: Docker
    Dockerfile: Dockerfile.render
    Region: Singapore

    Environment Variables:
    Key: TELEGRAM_TOKEN
    Value: [TOKEN dari @BotFather]

5️⃣  DEPLOY

    Click "Create Web Service"
    Tunggu 3-5 menit
    ✅ Bot online!
